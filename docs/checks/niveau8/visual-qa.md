# Check — UX and visual QA

PASS only if the exact changed routes are opened in a local browser and evidence shows:

- desktop 1440x900 and compact 390x844 inbox/list/thread/composer states;
- loading, empty, stale/offline, and error states are visually distinct and readable;
- keyboard focus is always visible and follows list navigation without unexpected scroll jumps;
- shortcut help is searchable, contextual, and does not advertise missing handlers;
- reduced-motion preference removes non-essential movement;
- no horizontal overflow, clipped dialog, unreadable contrast, or console error in the smoke flow.
