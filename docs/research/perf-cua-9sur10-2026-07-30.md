## Incident d'environnement documenté (harness de test)

L'ajout d'un **second site d'appel** `import()` du même module mocké
(préchauffe + factory `React.lazy`, dans le même tick) fait perdre le mock à
vitest 3.2.7 par intermittence : le module réel s'évalue et le test de contrat
palette échouait (`No "useParams" export…`). Corrigé **dans le code produit**
par la promesse d'import mémoïsée (un seul appel réel, pattern souhaitable en
soi), plus un flush déterministe (`vi.waitFor`) dans le test — contrat
inchangé. À savoir pour tout futur préchargement d'un module aussi consommé
par `React.lazy`.
